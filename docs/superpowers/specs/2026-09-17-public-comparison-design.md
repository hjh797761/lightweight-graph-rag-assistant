# 单卡公开检索对比与项目展示设计

日期：2026-09-17。用户已确认单卡短任务、公开检索实验、README 展示与测试后推送 main；本次增加开源项目对比。以下是实施范围，尚无 GPU 实验结果。

## 目标与发布原则

面向中文 RAG 开发者与项目评审者，验证检索质量、建库成本和查询成本。内部保留成功、失败、超时及不占优势的结果。若没有值得宣传的优势，可不发布对比文章；发布优势时链接该轮完整指标、条件与失败数量。只对实测任务与版本作结论，不能由更快推断质量更高。

## 对比项目

1. LlamaIndex 向量检索配置，作为外部框架实现，不代表整个 LlamaIndex 的最优能力。
2. HKUDS/LightRAG，分别记录 naive 与 mix 模式；先检查模型、原始证据映射与建库预算。
3. Microsoft GraphRAG，成本可控时才扩展。官方提示建库成本较高，首轮不强求纳入。

对手使用明确发布版本与官方接口，不修改其算法来降低表现。每个项目使用独立环境，防止本仓库 graphrag 包与 Microsoft 同名包冲突。

## 公平性与数据

先验证 CRUD-RAG 的文档、查询、相关性标签能否准确对应。只有完整相关文档标注才可称 document Recall/MRR/nDCG；答案字符串命中只称答案/证据覆盖代理指标。无法映射的题目及原因进入数据审计，不能根据分数删题。小语料结果明确标为子集，不声称是全量 CRUD-RAG 成绩。

开发/留出按来源文档分组约 40/60 划分；关联多篇来源的题目归同一组，避免同源问答跨组泄漏。首次 20–30 题检验链路，再用约 200–300 题评测。所有系统使用同一候选语料，检索不获得题目的正确来源限定。各 embedding 模型独立建库。

可控组件比较尽可能统一切块、embedding、重排器、候选数量、最终证据预算和硬件。原生系统有不同切块或 LLM 抽取需求时单列系统级比较，并记录差异。图生成的实体、关系和摘要不能直接冒充相关原始文档；只有可追溯来源参与原文档指标。每个查询保存实际返回数量。

## 已发现的适配风险

- 当前 scripts/retrieval_eval.py 将问题的 document 传作 doc_scope，这是限定文档烟测，不是全库检索。
- 该脚本直接构造 Retriever，未安装配置中的 reranker，模型配置名不能作为已启用证明。
- full 配置动态返回 3–6 个片段，报告必须展示实际条数；不得把较少返回造成的低耗时直接归因于加速。
- 当前关键词/图候选可能超过 vector_recall_k，需记录实际候选数，明确是否采用统一截断策略。
- Qwen3 reranker 不能仅替换 BGE CrossEncoder 的模型名称；须按官方 yes/no 打分接口实现并验证。
- 在线生成回答依赖 API；免费本地演示先展示检索证据，不将模板拼接冒充模型回答。

## 指标与运行

质量：有可审计相关性标签时计算 Recall@5/10、MRR@10、nDCG@10，按统一文档 ID 去重。无结果计 0；缺失标签不当作 0 质量。工程指标：冷/热查询耗时、P50/P95、串行吞吐、建库耗时、索引体积、内存/显存、LLM 调用量及 GPU 时长。未测值写 null，不填 0。

先 sbatch --test-only 估计单卡短任务，再真实提交一个任务，使用 squeue --start 查询；估计缺失记 unavailable。真实运行由 sacct 的状态、开始/结束与退出码核实。默认 1 节点 1 GPU、4 CPU、32GB、15 分钟探测，正式试验 30–60 分钟。4090/L40 由实际队列选择。不得因为别的用户排队或同账号有作业就取消它们；只处理本任务创建的作业。

本机只做 CPU 测试。集群网络下载与计算分开，计算在分配的计算节点执行。项目目录由集群只读检查确定，不在共享 /data2 根目录直接写入。

## 文件与执行顺序

1. 增加独立评测输入与指标，使用普通 ID、配置 JSON 与逐题 JSONL，不添加额外 hash 或冻结机制。
2. 接入 LlamaIndex 向量检索，先验证真实依赖与候选 ID 一致性；LightRAG 完成少量建库后才决定扩大规模。
3. 增加 Slurm 探测、提交与查询说明，短任务先行，保存排队与运行状态。
4. CPU 测试覆盖排名/去重、数据分组、空结果、缺失查询与全库检索；GPU 探测验证真实模型加载、编码与重排。
5. 真实数据审计和试运行通过后进行留出评测。汇总包含所有所选方法与全部指定指标，不自动只挑胜出项。
6. 真实证据到位后更新 README、录制演示、发布 Release。大数据与原始内部试验默认保留在 .tmp，公开汇总由人工明确选择。
